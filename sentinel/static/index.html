Which machine catches which payload?

Type or pick a payload. It is sent as a search query through every machine. Payloads that only the pushdown automaton or the grammar flag show why a DFA alone is not enough.

Why more than a DFA?

A DFA has finitely many states and no memory, so it can recognise exactly the regular languages. Fixed keywords such as union select and bounded counters ("5 failed logins in a row") are regular.

Matching brackets ((…)) and matching tags <a><b></b></a> are not. The language { (ⁿ )ⁿ } fails the pumping lemma: pump the opening brackets and the string no longer balances. A finite-state machine cannot count unbounded depth, but a pushdown automaton can, using its stack.

A context-free grammar describes the structure of an injected SQL condition (' OR (1=1 AND (2=2)) --); the parse tree is the proof that the text is a valid injected expression.
